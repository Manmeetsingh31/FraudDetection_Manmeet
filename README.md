## ⚙️ Setup Instructions

### 1. Clone / Download the project folder

```bash
# If submitted as ZIP, unzip it first
unzip FraudDetection_Manmeet.zip
cd FraudDetection_Manmeet
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Get the real dataset (Kaggle)

> The synthetic data included allows the notebook to run end-to-end.
> For real results, replace the files in `data/` with the official Kaggle files.

1. Go to [https://www.kaggle.com/c/ieee-fraud-detection/data](https://www.kaggle.com/c/ieee-fraud-detection/data)
2. Download `train_transaction.csv` and `train_identity.csv`
3. Place both files in the `data/` folder

### 4. Run the notebook

```bash
jupyter notebook analysis.ipynb
# Run all cells — this generates model.pkl, all charts, and model_comparison.png
```

### 5. Launch the Streamlit dashboard

```bash
streamlit run dashboard/app.py
```

The dashboard opens at **http://localhost:8501**

## 🚀 Deploy on Streamlit Community Cloud

1. Push this entire folder to a **public GitHub repository**
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**
3. Connect your GitHub repo
4. Set **Main file path** to: `dashboard/app.py`
5. Click **Deploy** — live URL will be provided within ~2 minutes

## ⚠️ Important Notes

- **SMOTE is applied only on training data** — test set is never touched during oversampling
- **Optimal classification threshold** is chosen by maximizing F1-Score, not fixed at 0.50
- **SHAP values** are computed with `TreeExplainer` (exact, not approximate)
- The dashboard requires `dashboard/model.pkl` — run the notebook first to generate it
